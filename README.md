# Ruggero Umbrel apps

Community App Store for umbrelOS. In Umbrel: *App Store → ⋯ → Community App Stores* → add `https://github.com/RuggeroCapo/umbrel-apps`.

- **HomeNet** — router watchdog and traffic analytics ([source](https://github.com/RuggeroCapo/homenet))
- **Personal Library** — reading companion with a Hermes-powered librarian and Kindle delivery ([source](https://github.com/RuggeroCapo/personal-library))
- **Send to Trilium** — summarizes links, PDFs and videos with Gemini into Trilium Notes ([source](https://github.com/RuggeroCapo/send-to-trilium))
